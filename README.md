# 📸 Pixel Fudge

Pixel Fudge is a modern full-stack SaaS platform for **editing images and videos online**, built with performance, scalability, and user experience in mind. Designed for creators, businesses, and enthusiasts, it provides a clean UI, powerful media manipulation tools, and a secure authentication system.

> **Note:** This is a **public-facing demo**. Sensitive backend logic has been removed for security purposes. You may clone and configure it for full functionality. Contact me if required.

---

## 🚀 Features

- ✨ Fully responsive UI built with **Next.js App Router**
- 🔐 Authentication powered by **Clerk**
- ☁️ Media storage and transformation via **Cloudinary**
- 🎨 Tools to edit images and videos (cropping, filters, trimming etc.)
- 🌐 Serverless API routes for uploads and processing
- 📂 Secure file handling with drag-and-drop and previews
- 📦 Modern development stack using TailwindCSS and JavaScript

---

## 🧱 Tech Stack

| Layer              | Technology            |
|--------------------|------------------------|
| Frontend           | Next.js 14 (App Router), React 18 |
| Backend/API        | Next.js API routes     |
| Auth               | Clerk.dev              |
| Media              | Cloudinary             |
| Styling            | TailwindCSS  |
| Image Handling     | Cloudinary API + Client-side previews |
| Deployment         | Vercel  |

## 🛠️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/pixel-fudge.git
cd pixel-fudge

### 2. Install Dependencies

```bash
npm install
```

### 3. Set up Environment Variables

Create a `.env.local` file:

```bash
touch .env.local
```

### 4. Run the Dev Server

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000)

## 📦 Deployment

### Deploy on Vercel

1. Push your repo to GitHub
2. Import it in [Vercel](https://vercel.com/)
